# Window Functions:
- A window function calcultes a value for each row in the result set based on a subset of the rows that are defined by a window specification.
- The window specification is defined using the OVER() clause in SQL, which specifies the partioning and ordering of the rows that window function will operate on. The partioning divides the rows into groups based on a specific column or expression, while the ordering defines the order in which rows are processed within each group. 
-- Window Function -> return the result row by row. 
-- GROUP BY        -> return the result based on the group.

-- Aggregate function :-
-- OVER clause exactly similar to GROUP BY. 
-- 

-- Frames. 
-- A frame in a window function is a subset of rows within the partition that determines the scope of the window function calculations. The frame is defined using a combination of two clause in the window function: ROWS & BETWEEN.
