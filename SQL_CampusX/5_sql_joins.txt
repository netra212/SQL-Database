SQL Joins:
- way to combine data from two or more database tables based on a related column between them. 

# Cross Joins --> Cartesian Products. 
returns the cartesian products of the two tables being joined. 

# Inner Joins
- Combines data from two or more tables based on a specified condition. 
- Joins on the basis of the common column. 
- Example:-
    Employee_ID     Name    Department_ID   Salary
    Department_ID   Department_Name
    Inner Joins Performs on the basis of Department_ID Only if the specified conditions meets. 


# Left Joins:-
- A left joins combines the rows from both tables based on a common column, but it also includes all the rows from the left tables, even if there are no matches in the right tables. This is useful when we want to include all the records from the first tables, but only some records from the second tables. 
- Left tables means first table we ware taking. 

# Right Joins:-
- Exactly opposite of the Left Joins. 

# Full Outer Joins:-
- Returns all the rows from the both tables like from left and right tables. 


# SQL SET Operations.
- UNION - combine the results of two or more SELECT statements into a single result set. The UNION operator removes the duplicates rows between the various SELECT statements.

- UNION ALL - The UNION ALL operator is similar to the UNION operator, but it does not remove duplicates rows from the result set. 

- INTERSECT - The INTERSECT operator returns only the rows that appear in both result sets of two SELECT statements.

- EXCEPT - The EXCEPT or MINUS operator returns only the distinct rows that appears in the first result set but not in the second result set of two SELECT statements.

# SELF Join
- A type of join in which a table is joined with itself. 
- This means that the table is treated as two separate tables, with each row in the table being compared to every other row in the same table. 
- Self joins are used when we want to compare the values of two different rows within the same table. For examples: if we want to compare the salaries of two employees who work in the same department, or to find all pairs of customers who have the same billing address.
